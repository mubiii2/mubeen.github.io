“What if you could reverse anything?”

Reverse It turns ridiculous everyday scenarios into unexpected interactive challenges. Instead of standard puzzle solving, players must discover how to reverse an action, undo a physical state, or make an event play out in backward sequence. From returning a hatched chick back into an unbroken eggshell to calming someone desperately holding it together in an executive meeting, each level is a self-contained comedic interaction.

  • Rapid Prototyping: Iterated and tested game loop ideas under tight game jam deadlines alongside the designer.

Technical Art & Editor Tooling

Optimizing pipeline assembly, responsive UI & performance

  • Custom Level Testing Tools: Built custom Unity Editor inspectors to trigger state overrides, fast-forward levels, and debug interactions in seconds.
  • Responsive Mobile Canvas: Configured multi-aspect ratio canvas scalers, anchor systems, and touch hitbox boundaries.
  • Asset Pipeline & Slicing: Handled 2D sprite imports, pivot alignment, and visual layer sorting directly in Unity.

01 // PROJECT OVERVIEW

Tactical Gunplay Meets High-Performance Optimization

CAMPUS 99 is a fast-paced tactical multiplayer first-person shooter set in an urban campus environment. Developed with Unity 6 and the Universal Render Pipeline (URP), the project was engineered to deliver competitive-grade gunplay, high visual clarity, and seamless peer-to-peer multiplayer without dedicated external server costs.

Technical Art & Real-Time Shaders

Custom URP shaders, occlusion tooling & visual telegraphing

  • Custom HLSL Team Silhouette Shader (CharacterHighlight.shader): Authored view-dependent Fresnel rim lighting with HDR color overdrive and tint controls for rapid target acquisition in complex architectural environments.
  • Always-Visible HUD Marker Shader (TeammateMarkerDot.shader): Custom unlit transparent pass with ZTest Always to display friendly indicators through walls with zero z-fighting.
  • Automated Occlusion & Batching Tool (OcclusionCullingSetup.cs): Created an internal editor utility that scans hierarchies, applies static tags using algorithmic heuristics, and bakes cell matrices to drastically cut draw calls and GPU overdraw.
  • Visual Ballistics & VFX Pipeline: Engineered muzzle flash bursts, parameterized trail tracers, particle impact debris, and surface decals with capped ring buffers.

Gameplay & Network Engineering

Multiplayer synchronization, ballistics & memory optimization

  • NGO + Unity Relay Networking: Integrated room-code matchmaking, NAT-punching lobbies, and client-interpolated transform replication (PlayerNetworkTransform.cs).
  • Raycast Ballistics & Dynamic Bloom: Programmed continuous fire recoil accumulation, camera shake, and procedural weapon bobbing (WeaponController.cs).
  • Hierarchical Bone Hitbox System (Hitbox.cs): Implemented regional hit detection with headshot multipliers (critical/one-shot) validated server-side.
  • Zero-Allocation Object Pooling: Built decoupled recycling pools for bullet tracers, dynamic 3D spatialized flyby/impact audio, and decals, eliminating GC micro-stutter.

01 // PROJECT OVERVIEW

Satirical Fortune-Telling & Rigged Comedy Trials

Doctor Guruji is an interactive narrative comedy game where players consult an eccentric spiritual guru (“Guruji”) to uncover their destiny. Through an escalating sequence of rigged trials—from a physics-based heart-shattering minigame to a high-stakes three-card monte illusion and celestial falling fortunes—the player discovers that destiny has an unexpected price: a mandatory ₹100 digital consultation fee backed by comical payment rejections.

Technical Art & Custom Shaders

HLSL cloth displacement, pseudo-3D transforms & layout automation

  • Custom HLSL Hanging Cloth & Wind Shader (HangingClothWind.shader): Authored dual-harmonic compound vertex displacement with exponential top-edge pinning (_PinTop) and multi-octave UV ripple billow, simulating realistic banner physics on uGUI canvas elements.
  • Procedural Surface Fold Shading: Integrated fake ambient occlusion and creased highlight calculations based on simulated cloth folds to give 2D banners tactile depth.
  • Pseudo-3D 2D Card Flip Illusion: Programmed a cosine-interpolated X-scale squash-and-stretch pipeline mimicking 3D card flips purely in Unity uGUI canvas space without Z-fighting.
  • Sinusoidal Arc Shuffling: Animate card swaps dynamically across slots using parabolic trajectory arcs (Mathf.Sin(t * π) * 45px) to avoid visual overlap.
  • Runtime UI Anchor Sanitizer: Engineered custom runtime layout sanitization (EnsureCorrectAnchoring()) to guarantee pixel-perfect registration across 16:9, 18:9, and ultrawide displays.

Gameplay Architecture & Sound Systems

Decoupled minigames, audio ducking & dialogue engine

  • Modular Minigame State Architecture: Built decoupled, event-driven minigame controllers orchestrated by a centralized state machine (GurujiQuestionPhaseManager & Level1FlowManager).
  • Real-Time Dynamic Audio Ducking: Developed a thread-safe priority token audio subsystem (BackgroundMusicManager) featuring logarithmic volume ducking during voice lines, restoring ambient BGM seamlessly upon completion.
  • Voice-Synchronized Typewriter Subtitles: Engineered a character-by-character typewriter subtitle system with procedural sound blips, cadence delays, and dynamic font glyph sanitization.
  • Procedural 2D Shatter Physics & Haptics: Programmed directional impulse shattering for the Heart Break trial (HeartShard.cs) alongside decaying sinusoidal screen shakes for payment rejections.
  • Hot-Plug Smart Component Discovery: Wrote reflective auto-binders that scan object hierarchies at runtime, preventing broken inspector bindings and missing null references.

01 // PROJECT OVERVIEW

Temporal Paradoxes, Environmental Causality & Collapsing Timelines

When a temporal experiment goes catastrophically wrong, a physicist from 2025 is flung decades into the past. Stranded in 1990, he must travel backward through time—to 1970, 1950, and beyond—to reverse what he broke. Every leap across eras forces players to reconsider cause and effect: manipulating platforms in 1950 directly reshapes obstacles in 1990. But every jump incurs a heavy cost: if the temporal countdown expires, the scientist is marooned in the past forever, and history rewrites itself around him.

Technical Art & Era Visual Identity

Temporal post-processing, parallax depth & editor workflows

  • Temporal Color Grading & Era Visual Shifts: Built distinct visual aesthetics per historical period using custom volume color grading LUTs (sepia-tinted vintage warmth for 1950, retro CRT scanline vibes for 1990, and pristine modern sterile tones for 2025).
  • Layered Parallax & Multi-Plane Depth: Structured multi-depth background layers and custom parallax scrolling controllers, giving 2D levels cinematic visual perspective during rapid horizontal traversal.
  • Sprite Atlas Packaging & Draw-Call Batching: Unified hundreds of distinct period environment tilesets and architectural props into compact texture atlases, maintaining high performance and zero frame drops.
  • Cinemachine Dynamic Camera Bounds: Configured smooth camera damping with adaptive boundary colliders and zoom transitions when shifting between eras.
  • Temporal Transition FX: Programmed screen warp distortions and chromatic aberrations triggered during era leaps.

Gameplay Architecture & Mechanics

Multi-era state machines, timeline clocks & platform causality

  • Cross-Era Causality Architecture: Engineered decoupled state trackers linking physical actions across historical eras (e.g., activating a pressure switch in 1950 removes structural barricades in 1990).
  • Temporal Tension Countdown Subsystem: Developed an escalating timer subsystem with audio-visual distortion triggers that penalizes stalls and enforces urgency before history collapses.
  • Precise 2D Platformer Character Controller: Programmed a responsive kinematic controller featuring coyote time, jump buffering, variable jump heights, and moving-platform velocity inheritance.
  • Interactive Mechanism System: Designed modular interactive components (timed doors, motorized lifts, physical switches, laser barriers) using event-driven interfaces.
  • Scene & Checkpoint Flow Manager: Implemented seamless restart and checkpoint respawn logic that preserves puzzle causality state across era changes.

Gameplay Programming & Level Design

01 // PROJECT OVERVIEW

Tactile 2D Physics, Drag-to-Slash Spline Chains & Juicy Arcade Feedback

POP IT! is a juicy, physics-driven arcade puzzle game where players pop falling balloons and drag-to-slash multi-colored chains before the playfield overflows. Combining tactile 2D physics with a custom pseudo-3D lighting shader, adaptive difficulty pacing, and an exponential multiplier combo system, the game delivers an addictive, high-energy arcade experience engineered for seamless cross-platform play across WebGL, PC, and mobile touch screens.

Technical Art & Shader Engineering

Custom HLSL lighting, procedural normal reconstruction & visual juice

  • Custom Pseudo-3D Lighting Shader (JuicyBalloonShader): Wrote a handcrafted ShaderLab/HLSL shader that reconstructs spherical normal vectors mathematically across flat 2D sprite UV coordinates, granting flat balloon textures a tactile, high-gloss 3D presence.
  • Dual Specular Glints & Translucency: Simulated direct sun glints alongside a secondary ambient fill light, paired with subsurface rubber translucency for a candy/jelly latex appearance.
  • Fresnel Rim Sheen & Ground Bounce: Engineered subtle Fresnel edge glow and bottom meadow reflections, naturally grounding floating balloons inside the vibrant cartoon container.
  • Dynamic Selection Shimmer: Programmed real-time parameter modulation in the shader to produce a luminous pulsing highlight whenever a balloon is linked into an active slash chain.
  • Catmull-Rom Spline Gesture Trail: Rendered real-time slicing paths via an adaptive LineRenderer utilizing smoothed Catmull-Rom curve interpolation, neon glow gradients, and particle sparks.

Gameplay Programming & Systems Architecture

Decoupled physics hierarchy, fair-play algorithms & progression loop

  • Decoupled Visual vs. Physics Architecture: Solved physics collider micro-jitter and explosion artifacts by isolating Rigidbody2D and CircleCollider2D strictly on the root GameObject, while squash-and-stretch tweening scales a dedicated child VisualRoot.
  • Dual Input System (Tap-to-Pop vs. Drag-to-Slash): Engineered an ultra-responsive input handler supporting instantaneous single-tap pops alongside multi-color drag gestures with unified mouse and touch coordinate translation.
  • Fisher-Yates Shuffle-Bag Fair-Play RNG: Replaced raw random generation with a card-deck shuffle-bag algorithm, guaranteeing balanced color distribution and preventing impossible color droughts.
  • Quadratic Chain Scoring & Exponential Multipliers: Programmed combo math rewarding ambitious chains (Count × 20 × Count × Multiplier) with cascading Golden Star multipliers (2n) and a 10-point Fever Rush mode.
  • Dynamic Difficulty Pacing & Danger State Machine: Scripted survival-time escalation from single drops to 4-balloon hyper-bursts, guarded by a danger-line threshold alarm and countdown state machine.
